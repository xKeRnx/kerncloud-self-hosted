# Editions

This is the self-hosted application distribution. It includes the workspace, local accounts, projects, models, tools and execution services. The private operator's marketing site, landing pages and stock-photo assets are excluded. Changing an environment variable does not restore those files.

The operator separately maintains the hosted offering and public installer downloads. Do not copy operator credentials, customer data, billing configuration, private signing keys or original repository history into this repository. Desktop payload generation refuses an operator edition.

Self-hosting does not require a KeRnCloud cloud subscription. Your hardware and external AI providers can still incur costs. Permissions, project boundaries, budgets and sandbox controls remain active.
