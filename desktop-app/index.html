Service status

    Closing this window keeps services running. Stop services pauses your installation and preserves its data and permissions.

    First-time setup & Docker
    1. Prepare DockerInstall or start Docker. Confirm any OS permissions, license prompts or reboot yourself.
    2. Start locallyThe first start downloads the release images. Follow each step in Local services above. Later starts reuse the existing images.
    3. Sign in and connect a modelOpen your generated sign-in details, change the initial password and connect a model in the dashboard.

    Network & ports

    Localhost is the default. LAN access requires sign-in. Configure HTTPS for sensitive network access. Firewall and router rules are not changed automatically.

    Stop and start local services to apply changes. Existing data and permissions stay in place.

    App updates

    Downloaded updates can install the next time you open the app. Linux may request system permission. Local services keep running; your configuration, data and access permissions stay in place. Apply a new server version separately with Update local server, which creates a backup first.

    Manage your installation

    Uninstalling the app preserves your database, files and permissions. Server updates create a backup first.
