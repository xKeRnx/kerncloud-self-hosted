Network & ports

Localhost is the default. LAN access still requires sign-in. Use HTTPS for sensitive network access; public internet access requires a separate HTTPS/domain setup. No firewall or router rules are changed automatically.

Closing the app keeps local services running. Stopping or uninstalling the app preserves your database, files and permissions. Server updates create a backup first.
