2 · Local access boundaries

Only you can grant new permissions here on this device. Changes require the Bridge to be paused. The web app can restrict these boundaries further.

Allowed capabilities

Folders

Agents see an alias; the absolute local path stays on this device. Writing requires an additional web approval and creates a backup of existing files.

Websites & internal network targets

Enter the exact address, including protocol and port, e.g. https://intranet.example.com or http://192.168.1.20:8080. Only these targets are reachable; redirects are not followed automatically.

Approved programs

Choose a fixed program and fixed arguments; the agent cannot change either. Do not approve general shells, script interpreters or administrator tools.

3 · Startup & shortcuts

Startup is optional and off by default. The Bridge remains paused when it starts with the operating system.

Windows: choose desktop and Start menu shortcuts in Setup. Running Setup again changes that choice and preserves connections. macOS: move the app to Applications and optionally drag it to the Dock.

4 · Updates

The Bridge checks regularly for new versions. Updates preserve connections, keys, local permissions and the action history.

Loading update status…

Pause before installing and wait for running actions to finish. Linux may ask for operating system confirmation. The Bridge starts paused again afterwards.

5 · Know what is transferred

Read text, browser output, network responses and approved screenshots are transferred to your KeRnCloud workspace and may be sent to your selected AI model. Local execution can still involve cloud services.

Desktop actions also need local confirmation. Linux desktop input requires X11 and xdotool. macOS desktop actions require Screen Recording or Accessibility permission. The separate browser works independently.

After a restart, connection error or revocation, the Bridge stays paused. Completed external actions are not undone. If the outcome is uncertain, check the local state first.
